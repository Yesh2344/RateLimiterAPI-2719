## Overview

RateLimiterAPI is a production‑ready Spring Boot REST service that demonstrates a robust per‑IP rate‑limiting mechanism. It includes:

* Configurable limits via `application.yml` or environment variables
* Clean separation of concerns (controller, service, configuration, utilities)
* Global exception handling with proper HTTP status codes
* Comprehensive logging
* Unit tests with JUnit 5 and Spring Boot Test
* Ready‑to‑run Gradle build
